📌 Project Overview
This project involves a detailed analysis of 38,500+ bank loan applications to monitor lending health and risk[cite: 3]. [cite_start]It tracks Key Performance Indicators (KPIs) like Total Funded Amount, Average Interest Rates, and Debt-to-Income (DTI) ratios.

🛠️ Tech Stack
- Tool: Microsoft Excel (Pivot Tables, Advanced Dashboards) 
- Metrics: Good vs. Bad Loan tracking 
- Analysis: Regional (State-wise) and Purpose-based lending analysis 

📊 Key Business Insights
- Lending Health: Identified a Good Loan Percentage of 90.77%, with a **9.23% Bad Loan rate.
- Interest Trends: Established that the average interest rate across all applications is 12.05%.
- Regional Demand: Identified New York (NY) and California (CA) as top states for loan applications.
- Purpose Analysis: Debt consolidation emerged as the primary reason for loan requests.
